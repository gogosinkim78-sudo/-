# 경마 시스템 직업군·프로세스 도출 프롬프트

## 용도

"경마라는 시스템이 정상적으로 굴러가기 위해 어떤 직업군(이해관계자)이 참여하고,
어떤 프로세스를 거치는지"를 AI 어시스턴트(Claude, ChatGPT 등)에게 체계적으로
정리받기 위한 프롬프트입니다. 아래 프롬프트 블록을 그대로 복사해서 사용하거나,
`[ ]`로 표시된 부분만 상황에 맞게 바꿔서 쓰세요.

---

## 프롬프트 (복사해서 사용)

```
너는 [한국마사회(KRA) 기준 경마 산업] 전반에 정통한 시니어 컨설턴트다.
"경마라는 시스템이 하나의 경주일(race day)을 중심으로 정상적으로 굴러가기
위해 필요한 직업군(이해관계자)과 그들이 수행하는 프로세스"를 아래 지침에
따라 정리해줘.

1. 분석 범위 (밸류체인 6단계)
아래 순서를 기준으로, 각 단계에 실제로 관여하는 모든 직업군을 빠짐없이 도출해:
1) 생산·육종 (마주, 생산자, 종마관리 등)
2) 육성·조교 (조교사, 기수, 마필관리사 등)
3) 등록·검역·출전 준비 (혈통등록, 검역, 계량)
4) 경주 당일 운영 (심판/재결, 발주, 주로관리, 도핑검사, 응급의료, 중계)
5) 베팅·발매·정산 (발매시스템, 오즈 산정, 부정베팅 감시, 환급)
6) 감독·규제·팬서비스 (감독기관, 동물복지, 마케팅, 미디어/전문기자)

2. 각 직업군마다 다음을 표로 작성
| 단계 | 직업군(국문/영문) | 핵심 업무 | 주요 협업 대상 | 필요 자격·면허 |

3. 엔드투엔드 프로세스 흐름
표 작성 후, 말 한 마리가 태어나서 실제 경주에 출전해 베팅이 정산되기까지의
전체 흐름을 시간순 번호 목록으로 요약하고, 각 단계마다 어떤 직업군이
개입하는지 괄호로 표시해줘.

4. 리스크 포인트
프로세스 중 오류·사고·부정이 발생하기 쉬운 지점 3~5개를 짚고, 이를
예방·대응하는 직업군의 역할을 설명해줘.

5. 출력 형식
- 마크다운, 단계별 ## 헤더로 구분
- 표는 GitHub Flavored Markdown 표 사용
- 마지막에 전체 직업군 수와 단계별 인원 비중을 요약하는 총괄 표 추가
- 실무 참고용 보고서 톤(과장된 수식어 없이 정보 위주)
- 분량은 A4 2~3장 내외

한국 경마(한국마사회) 체계를 기본 전제로 하되, 필요하면 해외 사례
(영국 BHA, 홍콩자키클럽, 일본 JRA)와 다른 점을 짧게 각주로 덧붙여줘.
```

---

## 사용 팁

- `[ ]` 부분을 실제 대상 기관(예: 한국마사회, 일본 JRA, 홍콩자키클럽)으로
  바꾸면 더 정확한 답변을 받을 수 있습니다.
- 특정 단계만 더 깊게 알고 싶다면 "3번 항목은 생략하고 5단계(베팅·발매)만
  더 상세히 다뤄줘" 같은 문장을 뒤에 추가하세요.
- 신입 교육자료, 사업 기획서, 시스템 설계 문서 등 용도에 따라
  "5. 출력 형식"의 톤과 분량 지시를 조정해서 쓰면 됩니다.
